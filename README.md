# Marie Fujimoto Portfolio

Static portfolio website for GitHub Pages.

## Publish to GitHub Pages

1. Create a GitHub repository named `mariefujimoto.github.io` if your GitHub username is `mariefujimoto`.
2. Add `index.html`, `styles.css`, and `script.js` to the root of the repository.
3. Commit the files to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)`, then save.
7. Open `https://mariefujimoto.github.io/` after GitHub finishes publishing.

## Before publishing

Confirm your exact GitHub username. GitHub Pages user sites must use the exact repository name `<username>.github.io`.
